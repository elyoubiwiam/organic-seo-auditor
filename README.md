# SEO Insights Hub

I want to build a Search Console & Organic Performance Auditor app, similar in format to the UX audit.

Key requirements:
1. Automated organic performance analysis: surface high-impression low-CTR pages, decaying search queries, striking-distance keywords (rank 11-20), and quick-win SEO recommendations.
2. Demo mode / preloaded sample data: include realistic sample datasets with a one-click demo audit so users can test and explore the full report immediately without needing their own Search Console account connected. Also support uploading GSC CSV exports or connecting Search Console.
3. Strategic Analysis section: a dedicated section explaining what each finding means in plain business language and step-by-step guidance on how to improve the organic growth strategy.
4. Competitor & Industry Benchmarks: compare CTR curves against industry benchmarks by position, and highlight competitor content and keyword gap opportunities (using industry benchmark curves and content gap heuristics; external SEO API integrations deferred for later).
